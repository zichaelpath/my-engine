# Temple Run chunks — format 1 (Lesson 73)
#
# A chunk is one authored vertical slice of the climb, 200 units
# tall, in chunk-local coordinates: x across the 800-wide shaft,
# y DOWN from the chunk's top. platform=x|y|w|oneway, with an
# optional patrol extension |toX|toY|speed.
#
# Every chunk opens on the same entry landing (centre, y=165)
# and leaves from the same exit landing (centre, y=25), so ANY
# chunk can sit on ANY other and the climb never breaks: the
# deal varies the middle, the bookends keep it honest. Every
# hop stays inside the jump's reach (rise ~102, range ~145):
# no step up over 55, no edge gap over 130.
