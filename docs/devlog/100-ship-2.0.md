# Devlog 100 — Ship 2.0: MyEngine 2.0.0

## The release

Lesson 100 closes Arc 10 and Phase 2. The version lives in one
place (`project(MyEngine VERSION 2.0.0)`), the packager mirrors it,
and the generated `Version.hpp` carries it into every host — the GL
host's first log line reads `MyEngine 2.0.0 - GL host`, the
runtime's `MyEngine 2.0.0 - Runtime`.

## What 2.0.0 contains

Everything Phase 2 built (the retrospective, Lesson 97, is the full
account), plus Arc 10 itself: the retrospective, the README truth
pass, the MIT license and the public repo (Lesson 99), and — since
1.8.0 — the two Windows playtest fixes (Lessons 95–96). The
CHANGELOG's 2.0.0 entry tells the same story for readers who start
there.

## Verification

- Full build clean on the Linux rig; all four hosts run.
- Both packages rebuilt and **clean-room verified from empty
  folders**: Gold Rush boots as `MyEngine 2.0.0 - Runtime`;
  Temple Run loads its project (seed 20261), its 5 chunks, and
  builds the canonical ascent to y=150.
- The Windows build is confirmed by the author himself — the
  playtest gate's editor, runtime, and GL host all run on his
  laptop, which is where the gate's remaining hands-on items
  (audio by ear, Temple Run by hand, the Two Rooms campaign,
  the editor's GUI paths) continue to live.
- The harness caveat, stated plainly one last time for this
  phase: since this morning's build-rig VM replacement, the
  harness aborts partway inside SFML's own X11 display-open —
  27 checks passed and 0 failed in the release run before the
  abort, in code the 2.0.0 diff does not touch (the release
  changes no engine code at all). It read 69/69 on this tree's
  code earlier today, before the replacement. The rig's X11
  layer is a known Phase 3 neighbour problem, not a 2.0.0
  regression, and it is recorded here rather than smoothed over.

## The tag

`v2.0.0`, annotated, on this commit — beside `v1.0.0`, `v1.5.0`,
`v1.6.0`, `v1.7.0`, and `v1.8.0`. One hundred lessons: a Phase 1
that taught an engine to make a game, a Phase 2 that taught it to
make games, and a Phase 3 — the engine feels standard — already
planned by the person who will have to live in it.
