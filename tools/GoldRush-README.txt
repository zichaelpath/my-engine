GOLD RUSH
=========

Collect all 40 gold dots scattered across the world — against the
clock. Water slows you down, deep water most of all, so the fastest
route is rarely the straight one.

CONTROLS
  WASD / Arrow keys   Move
  Enter               Start (from the title screen)
  P or Esc            Pause (Esc quits from menus)
  R                   New world (after you win)

Your time stops the moment the last dot is collected. Every new
world is a fresh seed — no two runs share a map.

Built with MyEngine, a from-scratch C++ game engine
(C++20, SFML 3, Dear ImGui). Every sound in the game, including
the music, was synthesized in code — no recordings were used.

The font is DejaVu Sans (see assets/DejaVu-LICENSE.txt).
