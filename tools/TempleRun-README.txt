TEMPLE RUN
==========

Climb. The pressure is rising behind you, and it does not stop.
Your score is the highest your feet have ever been — every chunk
of the temple is dealt from the temple's seed, so this mountain
is always the same mountain. Learn it. Climb it higher.

CONTROLS
  A/D or Left/Right   Move
  Space / W / Up      Jump (hold for a higher jump)
  Enter               Start (from the title screen)
  P or Esc            Pause (Esc quits from menus)
  R                   Climb again (after the pressure takes you)

One-way platforms let you jump up through them and land on top.
The orange platforms move — ride them, but do not trust them to
wait. When the glow reaches your feet, the climb is over.

Built with MyEngine, a from-scratch C++ game engine
(C++20, SFML 3, Dear ImGui). Every sound in the game, including
the music, was synthesized in code — no recordings were used.

The font is DejaVu Sans (see assets/DejaVu-LICENSE.txt).
